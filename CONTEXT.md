# Bapenda service status

The public status page reports access to Bapenda Garut's monitored services, the health of SAPADA integrations, and updates published by its administrators.

## Language

**Layanan**:
One monitored public Bapenda website.

**Komponen**:
One SAPADA integration shown beneath the SAPADA service. Its check runs from the SAPADA server so VPN routes can be reached. The public page does not expose private endpoint URLs.

**Informasi layanan**:
A public report of a disruption or planned maintenance with one update timeline. It can concern one layanan or all monitored layanan.
